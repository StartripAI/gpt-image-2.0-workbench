# Using image2-workbench in web ChatGPT

This guide is for non-developers — designers, students, marketers, product
folks — who want to generate images by chatting with ChatGPT and don't
want to install anything. You will not need Python, an API key, or a
terminal.

## What you need

- A ChatGPT account on a plan that includes image generation
  (Plus, Pro, or Team).
- A web browser.
- A few minutes to copy and paste.

That's it.

## The five-step workflow

1. **Open the gallery for your domain.** The four V1 domain pages are:
   - [`docs/gallery/business.md`](./gallery/business.md) — SWOT cards,
     pitch slides, LinkedIn carousels, dashboards.
   - [`docs/gallery/academic.md`](./gallery/academic.md) — diagrams,
     proofs, edu-posters, journal posters.
   - [`docs/gallery/uiux.md`](./gallery/uiux.md) — iOS mockups, web
     dashboards, design-system cards, social covers.
   - [`docs/gallery/anime.md`](./gallery/anime.md) — character sheets,
     comic panels, city posters, candid scenes.

2. **Find a template that matches your scenario.** Each template has a
   short description. Skim until one fits. If nothing fits, go up to the
   neighbouring domain — boundaries are soft.

3. **Choose a language.** Each template is rendered twice, once in
   `zh-CN` and once in `en`. Pick the language you want the *brief* to be
   in. The text *inside the image* comes from the variables you fill in
   next, so a Chinese-language brief can still produce an image with
   English text and vice versa, but matching is usually best.

4. **Copy the compiled prompt block.** It's the fenced code block
   directly under the template's heading. Select it all and copy.

5. **Paste into ChatGPT and tweak.** Open a new ChatGPT conversation
   with image generation enabled. Paste the prompt. Before sending, find
   the placeholders — they look like `<angle brackets>` — and replace
   each with your real content. Then send.

ChatGPT will return an image generated by the same `gpt-image-2` model
the CLI uses. There is no difference in model capability — only in
runtime convenience.

## Tips that materially improve results

- **Replace every placeholder.** The model can sometimes render literal
  `<angle brackets>` into the image if you forget to replace them.
- **Keep text short.** If a placeholder asks for a title, give it a
  title — not a paragraph. The seven-section DSL assumes short literal
  strings; long ones blur.
- **Don't add extra instructions on the side.** "Also make it more
  vibrant" or "in the style of Studio Ghibli" attached to the end can
  fight with the structured brief. If you want to override style, edit
  the `style:` line in the prompt itself before pasting.
- **Re-roll if needed.** Image generation is non-deterministic. If the
  first render misses, ask ChatGPT to "regenerate" rather than rewriting
  the prompt — keep the structure constant and let randomness do its job.

## Worked example 1 — a SWOT card

Open `docs/gallery/business.md` and locate `business_swot_card`. The en
block will look something like this once V1 builds are wired up
(simplified for illustration):

```text
subject: a 2x2 SWOT analysis card for <COMPANY_NAME>, filling the canvas
action: the four quadrants are arranged S/W/O/T clockwise from top-left
scene: minimalist white background, soft drop shadow, studio lighting
composition: head-on flat view, 3:2 aspect ratio, equal-weight 2x2 grid
style: flat infographic vector, two-tone palette, confident sans-serif
text_blocks:
  - title: "SWOT Analysis"
  - quadrant_s: "<STRENGTH_1>"
  - quadrant_w: "<WEAKNESS_1>"
  - quadrant_o: "<OPPORTUNITY_1>"
  - quadrant_t: "<THREAT_1>"
preserve: []
negative:
  - NO stock-photo people
  - NO text other than the items in text_blocks
```

To use it: replace `<COMPANY_NAME>` with the real company, fill the four
quadrant strings (each ≤ 80 characters), then paste into ChatGPT.

## Worked example 2 — an XHS social cover

Open `docs/gallery/uiux.md` and locate `uiux_social_cover_xhs`. After
filling placeholders, a real prompt might look like:

```text
subject: a Xiaohongshu cover image for a skincare review post
action: the title sits centre-top, three product thumbnails align below
scene: warm pastel gradient background, soft natural light
composition: 3:4 portrait, 8% safe-area margin, rule-of-thirds focal point
style: soft-focus lifestyle photography blended with vector overlays
text_blocks:
  - hook: "三款敏感肌乳液真实对比"
  - tag: "成分党 / 实测 / 不踩雷"
preserve: []
negative:
  - NO watermarks
  - NO logos other than the brand mark in text_blocks
```

Note the Chinese strings inside the image text even though the brief
itself is in English — that's deliberate. The brief language is what the
model reads as instructions; the quoted strings are what it renders into
the image. They can differ when your audience and your authoring context
do.

## What this path doesn't give you

- No saved sidecar metadata (request, response, cost) — ChatGPT's tool
  doesn't expose those.
- No batch generation — one chat, one image at a time.
- No deterministic re-runs — the model picks a fresh seed each turn.

If any of those matter to your workflow, go to
[`getting-started.en.md`](./getting-started.en.md) and walk through the
CLI path instead. Same templates, more knobs.
