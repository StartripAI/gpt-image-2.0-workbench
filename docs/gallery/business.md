# Business gallery

Bilingual prompt templates for business deliverables — strategy artifacts,
pitch slides, social-publishing carousels, and data dashboards. Each
template is rendered twice: once to `zh-CN` and once to `en`. Copy the
block in the language you want and paste into ChatGPT.

> **V1 build status:** the four templates listed below are owned by the
> domain-template agents and are being authored in parallel with this
> gallery page. The compiled prompt blocks below are placeholders. Once
> the build is wired up (see [`../form-factors.md`](../form-factors.md)),
> running `i2w template render <id>` against each YAML will refresh
> these blocks automatically.

## Templates in this domain

| Template id | Description |
|-------------|-------------|
| `business_swot_card` | A 2x2 SWOT analysis card for a single company |
| `business_pitch_slide` | A pitch-deck title slide with headline and subhead |
| `business_linkedin_carousel` | A multi-slide LinkedIn carousel cover |
| `business_data_dashboard` | An executive KPI dashboard mockup |

### business_swot_card

A 2x2 strengths / weaknesses / opportunities / threats card filling the
canvas — designed for one-page strategic snapshots.
