# UI / UX gallery

Bilingual prompt templates for product and interface deliverables — iOS
mockups, web dashboards, design-system documentation cards, and
social-publishing covers. Each template is rendered twice: once to
`zh-CN` and once to `en`. Copy the block in the language you want and
paste into ChatGPT.

> **V1 build status:** the four templates listed below are owned by the
> domain-template agents and are being authored in parallel with this
> gallery page. The compiled prompt blocks below are placeholders. Once
> the build is wired up (see [`../form-factors.md`](../form-factors.md)),
> running `i2w template render <id>` against each YAML will refresh
> these blocks automatically.

## Templates in this domain

| Template id | Description |
|-------------|-------------|
| `uiux_ios_app_mockup` | A single iOS app screen mockup with chrome and content |
| `uiux_web_dashboard` | A web-app dashboard mockup with sidebar and main panel |
| `uiux_design_system_card` | A design-system documentation card |
| `uiux_social_cover_xhs` | A Xiaohongshu (RED) cover image, 3:4 portrait |

### uiux_ios_app_mockup

A single iOS app screen mockup — status bar, navigation chrome, content
area populated with realistic dummy content, and a tab bar. Designed
to look like a real screenshot, not a wireframe.

> Compiled bilingual prompt will appear here once the template is rendered.
> Run: `i2w template render uiux_ios_app_mockup --lang en` and paste the
> result. (V1 will auto-generate this once the build is wired up.)
