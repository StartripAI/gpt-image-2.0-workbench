# Anime gallery

Bilingual prompt templates for anime-style illustration deliverables —
character reference sheets, multi-panel comic pages, city posters, and
candid slice-of-life scenes. Each template is rendered twice: once to
`zh-CN` and once to `en`. Copy the block in the language you want and
paste into ChatGPT.

> **V1 build status:** the four templates listed below are owned by the
> domain-template agents and are being authored in parallel with this
> gallery page. The compiled prompt blocks below are placeholders. Once
> the build is wired up (see [`../form-factors.md`](../form-factors.md)),
> running `i2w template render <id>` against each YAML will refresh
> these blocks automatically.

## Templates in this domain

| Template id | Description |
|-------------|-------------|
| `anime_character_sheet` | A turn-around character reference sheet |
| `anime_comic_8panel` | An 8-panel comic page with consistent characters |
| `anime_city_poster` | A wide-format anime-style city poster |
| `anime_ccd_candid` | A candid slice-of-life scene with shallow depth of field |

---

### anime_character_sheet

A character reference sheet — front, three-quarter, and side views of a
single character on a neutral background, with a small palette swatch
strip and named expression studies.

> Compiled bilingual prompt will appear here once the template is rendered.
> Run: `i2w template render anime_character_sheet --lang en` and paste
> the result. (V1 will auto-generate this once the build is wired up.)

---

### anime_comic_8panel

An 8-panel comic page — gutter-separated panels arranged 2x4, each
showing the same character through a short narrative beat, with speech
bubbles where appropriate.

> Compiled bilingual prompt will appear here once the template is rendered.
> Run: `i2w template render anime_comic_8panel --lang en` and paste the
> result. (V1 will auto-generate this once the build is wired up.)

---

### anime_city_poster

A wide-format anime-style city poster — strong perspective lines, a
character anchored in the foreground, urban backdrop with mood
lighting. Designed to read well at poster scale.

> Compiled bilingual prompt will appear here once the template is rendered.
> Run: `i2w template render anime_city_poster --lang en` and paste the

### anime_ccd_candid

A candid slice-of-life scene shot as if on a CCD-era compact camera —
shallow depth of field, slight chromatic aberration, soft warm grade,
subject caught mid-action rather than posed.

> Compiled bilingual prompt will appear here once the template is rendered.
