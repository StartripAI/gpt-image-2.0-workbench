# Academic gallery

Bilingual prompt templates for academic and educational deliverables —
scientific diagrams, lecture-style proofs, multilingual edu-posters, and
conference-grade journal posters. Each template is rendered twice: once
to `zh-CN` and once to `en`. Copy the block in the language you want
and paste into ChatGPT.

> **V1 build status:** the four templates listed below are owned by the
> domain-template agents and are being authored in parallel with this
> gallery page. The compiled prompt blocks below are placeholders. Once
> the build is wired up (see [`../form-factors.md`](../form-factors.md)),
> running `i2w template render <id>` against each YAML will refresh
> these blocks automatically.

## Templates in this domain

| Template id | Description |
|-------------|-------------|
| `academic_scientific_diagram` | A labelled scientific diagram (biology / physics / chemistry) |
| `academic_chalkboard_proof` | A lecture-style chalkboard proof with hand-written equations |
| `academic_multilingual_eduposter` | An educational poster with bilingual labels |
| `academic_journal_poster` | A conference / journal poster layout |

---

### academic_scientific_diagram

A clean, labelled scientific diagram suitable for a textbook or lecture
slide — a cross-section, a process flow, or a system schematic, with
callout labels in legible type.

> Compiled bilingual prompt will appear here once the template is rendered.
> Run: `i2w template render academic_scientific_diagram --lang en` and
> paste the result. (V1 will auto-generate this once the build is wired
> up.)

---

### academic_chalkboard_proof

> Compiled bilingual prompt will appear here once the template is rendered.
