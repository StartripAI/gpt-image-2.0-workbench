# Domain: gaming

Fictional fantasy / sci-fi / RPG game creative — in-game UI, item
collectibles, and world-map panels for indie games and worldbuilding.

## FOR
- Fictional in-game HUD mockups (health bars, minimap, objectives)
- RPG / CCG-style collectible item cards with rarity and stats
- Fantasy quest-map / world-map panels for in-game codex screens
- Stylized painterly game aesthetics, not photoreal

## NOT FOR
- Real-product UI mockups or app screens (use `uiux/`)
- Sequential comic strips (use `anime/comic_8panel`)
- Anime character reference sheets (use `anime/character_sheet`)
- Real-world maps or photographic landscapes (use `travel/` or
  `architecture/`)

## Key visual axes
- HUD spatial discipline (corner clusters, banner zones, minimap)
- Card-frame ornamentation balanced with stat legibility
- Map cartography (parchment border, region labels, route legibility)
- Fictional-IP-only — no real game franchises or assets

## Templates in domain
- `gaming_hud_mockup` — mockup, 16:9, in-play HUD overlay
- `gaming_item_card` — poster, 3:4, RPG/CCG collectible card
- `gaming_map_panel` — diagram, 16:9, fantasy quest map
